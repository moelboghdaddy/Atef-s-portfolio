# Portfolio site

A self-contained site (no framework, no build tools beyond one small script) that turns a folder
of images into a portfolio homepage plus a page per project.

## Opening it

Just double-click `index.html`, or drag the folder into a browser. No server required.

## Adding your work

1. Inside `assets/`, make one folder per project (the folder name becomes the project title
   unless you set your own — see below).
2. Put your images in that folder, named by position:
   - `1L`, `2L`, `3L` … → a single image that spans the full width of its row
   - `2s L` + `2s R`, `4s L` + `4s R` … → two images that sit side by side on the same row
     (the number is the row, `L`/`R` is the side)
3. Add your logo as `assets/logo.png` (any image extension works), or put it inside an
   `assets/logo/` folder.
4. (Optional) Add an `info.json` file inside a project's folder to control its title,
   description, and order:

   ```json
   {
     "title": "Bumtee Rebrand",
     "description": "A rebrand and packaging system for a plant-based snack brand.",
     "order": 1
   }
   ```

   Without `info.json`, the folder name is used as the title, the description is left blank,
   and projects are ordered by the order their folders appear on disk.

5. From a terminal, inside this folder, run:

   ```
   node build.js
   ```

   This scans `assets/` and rewrites `js/data.js`, which the site reads. Run it again any time
   you add, remove, or rename images. (Requires Node.js — nodejs.org — nothing else.)

6. Refresh the page in your browser.

## Editing text

- **Hero heading, About, and Contact copy** live directly in `index.html` — search for the
  text and replace it.
- **Project titles and descriptions** come from each project's `info.json` (see above).

## A demo project is included

`assets/sample-project/` has placeholder images so the site works right out of the box. Delete
that folder (and re-run `node build.js`) once you've added your own.

## Files

- `index.html` — homepage
- `project.html` — project detail page template (reads `?p=slug` from the URL)
- `css/style.css` — all styling
- `js/main.js` — homepage behavior
- `js/project.js` — project page behavior
- `js/data.js` — auto-generated by `build.js`, don't edit by hand
- `build.js` — scans `/assets` and regenerates `js/data.js`
